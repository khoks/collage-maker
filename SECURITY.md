# Security policy

Collage Maker runs entirely in your browser, makes no network requests and never uploads your photos.
The installers only download release files from this repository and check their SHA-256 checksums.

## Reporting a vulnerability

Please report security problems privately through
[GitHub's private vulnerability reporting](https://github.com/khoks/collage-maker/security/advisories/new),
not in a public issue. You'll get a reply as soon as possible, and credit in the release notes if you'd like it.

## Supported versions

Only the latest release receives fixes.
